Designed for Trustworthy Scale

Controls make AI governable, not mysterious. Each risk from the design maps to a control that is actually implemented in this system.

Aligned to NIST AI RMF: transparency, accountability, human oversight.

Where it lives in GCA
Hallucination
Retrieval from bounded context only; source limits; HITL for high-stakes outputs.
LLM sees only the registry, the related domain, and its escalation paths. Any recommended role not in the registry is rejected before it is stored.
Authority drift
Role registry + escalation rules — not ad hoc decisions.
AI can only route to registered roles. Critical/high-risk domains and human-judgment domains are forced to HITL regardless of model output.
Privacy / security
RBAC, audit trails, approved data pathways.
Login required on every route; API key held only in server environment; every AI call and human decision written to the audit log.
Model failure
Deterministic rule-based fallback.
If the model is unavailable, times out, or returns malformed output, the same signal is routed through the encoded escalation path and successor chain. Fallback use is flagged on the signal and in the call log.
Adoption
Training + transparent purpose and limits.
Every AI output shows model, confidence, rationale, token cost and whether the rule-based fallback was used. Pilot page tracks user training.
