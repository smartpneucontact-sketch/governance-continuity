AI API Cost Model

The AI layer is a thin, metered call per governance event — not a model we train. Cost scales linearly with the number of monitored decision events, which keeps unit economics predictable.

Haiku-class pricing assumption. Because the AI only analyzes and routes — humans retain judgment — token volume stays bounded and cost grows with org size, not with risk.

Commodity stack

Flask + PostgreSQL + a metered LLM API. No bespoke infrastructure or model training required.

Stateless AI calls

Each signal evaluation is an independent API call — horizontally scalable and trivially cacheable.

Bounded unit economics

Cost-per-decision is a known KPI. Spend scales with org size, not with crisis severity.

Auditable by design

Every AI recommendation and human action is logged — compliance and explainability come for free.
